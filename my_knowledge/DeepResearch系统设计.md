# DeepResearch 深度研究系统设计

## 系统概述

DeepResearch 是一个基于大语言模型的自动化深度研究系统。它能够根据用户提交的研究课题，自主进行多轮搜索、信息抓取、分析整合，最终生成结构化的研究报告。

## 核心架构

### 研究流程

系统采用三阶段研究流程：

1. 规划阶段：LLM 将研究课题拆解为多个可独立研究的子问题，每个子问题包含描述和搜索词建议
2. 研究阶段：按子问题串行研究，每个子问题 1-2 轮搜索。如果来源质量评分达到 75 分则一轮通过，否则进行补充搜索
3. 报告阶段：汇总所有研究发现，生成结构化的 Markdown 报告

### 来源质量评分

系统使用纯规则引擎对搜索结果进行多维度评分：

- 来源权威度（30%）：基于域名白名单，政府/教育机构最高分
- 标题质量（25%）：检测标题党、无意义标题
- 摘要信息密度（25%）：是否包含具体数据和事实
- 关键词相关性（20%）：与搜索词的匹配程度

## 工具系统

系统为 LLM 提供以下工具：

- web_search_tool：互联网搜索，基于 Bocha API
- fetch_page_tool：网页内容抓取与清洗
- save_report_tool：报告保存
- kb_search_tool：私有知识库检索，基于 FAISS + bge-small

## 技术选型

- Web 框架：FastAPI + Uvicorn
- LLM 接入：OpenAI 兼容接口（DeepSeek）
- 向量检索：FAISS + BAAI/bge-small-zh-v1.5
- 异步任务：ThreadPoolExecutor + SSE 实时推送
