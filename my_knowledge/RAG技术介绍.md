# RAG 技术介绍

## 什么是 RAG

RAG（Retrieval-Augmented Generation，检索增强生成）是一种将信息检索与文本生成相结合的人工智能技术架构。它通过从外部知识库中检索相关文档，然后将这些文档作为上下文提供给大语言模型，从而显著提升生成内容的准确性、时效性和可溯源性。

## RAG 的核心原理

RAG 的核心思想是将检索系统与生成模型结合起来，形成一个端到端的流水线。当用户提出一个问题时，系统首先从知识库中检索与问题相关的文档片段，然后将这些片段与用户问题一起输入到生成模型中，生成模型基于检索到的上下文信息生成回答。

## RAG 的优势

相比传统的纯生成式模型，RAG 具有以下显著优势：

1. 知识可更新：无需重新训练模型，只需更新知识库即可使模型获取最新知识
2. 幻觉减少：基于真实文档生成内容，大幅降低模型编造事实的概率
3. 可解释性强：生成的答案可以追溯到具体的来源文档
4. 领域适配灵活：通过替换知识库，同一模型可以服务于不同领域

## RAG 的技术栈

典型的 RAG 系统包含以下核心组件：

- 嵌入模型（Embedding Model）：如 BAAI/bge-small-zh-v1.5、text2vec-large-chinese 等，负责将文本转换为向量表示
- 向量数据库（Vector Database）：如 FAISS、Milvus、Chroma 等，负责存储和检索向量
- 大语言模型（LLM）：如 DeepSeek、GPT-4 等，负责基于检索结果生成最终回答
- 文档处理流水线：包括文档解析、文本分块、元数据提取等
